클러스터 테스트 콘솔 (ClusterConsole.exe)
==========================================

QNX 8.0 위에서 도는 Qt 차량 계기판을 라즈베리 파이 4 또는 QEMU VM에 띄우고,
가상 ECU로 신호를 보내며 진단(DTC, UDS)을 시험하는 프로그램입니다.
exe 하나에 프로젝트 파일이 모두 들어 있고, 처음 실행할 때 이 PC의 환경을 점검해
빠진 것을 설치하거나 설치 방법을 알려 줍니다.

개인 학습용입니다. Qt와 QNX 이미지는 들어 있지 않으며 각자 받아서 빌드합니다.


1. 처음 실행할 때 나오는 경고 (Windows SmartScreen)
-----------------------------------------------------
이 exe는 코드 서명이 되어 있지 않아서, 처음 실행하면 "Windows의 PC 보호" 창이 뜰 수 있습니다.

  - "추가 정보"를 누른 뒤 "실행"을 누르세요.
  - 인터넷이나 메신저로 받은 파일이라 아예 실행되지 않으면:
    파일을 마우스 오른쪽 단추로 누르고 "속성" → 아래쪽 "차단 해제"를 체크 → "확인".

믿을 수 있는 사람에게서 받은 파일일 때만 이렇게 하세요.


2. 필요한 것
------------
공통
  - Windows 10 또는 11 (64비트), CPU 가상화가 켜져 있어야 합니다(작업 관리자 → 성능 → CPU → "가상화: 사용").
  - 디스크 여유 공간: QNX SDP(약 6GB)와 Qt 빌드(약 35GB)에 약 45GB.
  - QNX 계정(myQNX)과 무료 비상업 라이선스. 계정과 라이선스는 직접 만들어야 합니다.

라즈베리 파이로 띄울 때
  - 라즈베리 파이 4, 16GB 이상 microSD 카드(32GB 권장), 5V 3A 전원.
  - 이 PC와 같은 공유기(Wi-Fi)에 붙일 것.
  - 모니터는 없어도 됩니다. 화면은 UltraVNC 창으로 봅니다.

QEMU VM으로 띄울 때
  - 디스크 여유 공간 약 50GB 추가(QEMU 이미지).


3. 실행 순서
------------
  1) ClusterConsole.exe를 실행하고 "라즈베리 파이" 또는 "QEMU VM"을 고릅니다.
     파이는 "IP 찾기"를 누르면 같은 네트워크에서 파이를 찾아 IP를 채웁니다.
  2) 환경 점검 화면이 나옵니다. 모두 ✓이면 바로 시작합니다.
  3) ✕ 항목은 위에서부터 해결합니다.
       - "자동으로 고치기": 이 창이 알아서 합니다(프로젝트 설치, 빌드, Qt 복사).
       - "터미널에서 실행": 검은 창이 열립니다. sudo 비밀번호(우분투를 만들 때 정한 것)나
         파이 비밀번호(기본값 qnxuser)를 그 창에 입력하고 끝까지 진행합니다.
       - "설치": WSL이나 UltraVNC를 설치합니다. WSL은 PC를 다시 시작해야 할 수 있습니다.
       - 버튼이 없는 항목: 적힌 안내대로 직접 합니다(QNX 계정, SDK 설치, SD 카드 굽기).
     하나를 해결할 때마다 "다시 점검"을 누르세요.
  4) 시작하면 파이 화면(UltraVNC)과 테스트 콘솔이 열립니다.
  5) 콘솔 창을 닫으면 콘솔과 VNC 창이 닫힙니다. 파이와 VM의 프로그램은 계속 돕니다.

시간이 오래 걸리는 것
  - QNX용 Qt 빌드: 처음 한 번, 1~2시간 이상(PC 성능에 따라 다름).
  - QEMU VM 부팅: 1~3분.


4. 자주 생기는 문제
-------------------
  - 파이를 찾지 못함: 파이가 켜졌는지(부팅 약 1분), 이 PC와 같은 공유기인지 확인하세요.
    "Raspberry Pi OS(리눅스)로 부팅됨"이라고 나오면 QNX를 구운 SD 카드로 바꿔야 합니다.
  - "/dev/kvm 권한" 실패(VM): WSL을 다시 켤 때마다 필요합니다. "터미널에서 실행"을 누르세요.
  - SD 카드를 새로 구운 뒤 "호스트 키가 바뀌었습니다": 터미널 창의 안내대로
    ssh-keygen -R <파이 IP> 를 실행한 뒤 다시 하세요.
  - 화면이 검게 나옴(VNC): 파이를 다시 시작하고 1분 뒤에 다시 실행하세요.

명령줄 옵션
  ClusterConsole.exe --pi [--ip 192.168.0.10]    고르는 화면 없이 파이로 시작
  ClusterConsole.exe --vm                         고르는 화면 없이 VM으로 시작
  ClusterConsole.exe --distro Ubuntu-24.04        WSL 배포판 이름이 다를 때
